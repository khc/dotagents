## Overview
Provides a shared SQLite state store at `{project_root}/.sidecar/sidecar.db`.
Agents on the same project read and write this store to share context, pass intermediate results, and persist state across sessions.

Read/write operations are performed by Python scripts. The skill defines the schema contract and initialization procedure.

**Schema:** `skills/sidecar/schemas/sidecar.schema.sql`

## Schema
```sql
CREATE TABLE IF NOT EXISTS sidecar (
    id      INTEGER PRIMARY KEY AUTOINCREMENT,
    uuid    TEXT NOT NULL UNIQUE,
    project TEXT NOT NULL,
    skill   TEXT NOT NULL,
    scope   TEXT,
    agent   TEXT NOT NULL,
    model   TEXT NOT NULL,
    context TEXT,
    parent_uuid TEXT,
    status  TEXT NOT NULL DEFAULT 'open'
            CHECK (status IN ('open', 'pending', 'done', 'fixed', 'wontfix', 'superseded')),
    relation    TEXT
                CHECK (relation IN ('followup', 'fix', 'review', 'supersedes')),
    created_at TEXT DEFAULT (datetime('now')),
    updated_at TEXT DEFAULT (datetime('now')),
    FOREIGN KEY (parent_uuid) REFERENCES sidecar(uuid)
);
```

- `uuid` — generated by the caller (Python `uuid.uuid4()`)
- `project` — same for all entries in this DB; acts as a guard against cross-project data leaks
- `skill` — name of the skill that created the entry (e.g. `review`, `commit`)
- `scope` — active scope path within the project (optional, e.g. `src/api`)
- `agent` — agent runtime (e.g. `claude_code`, `codex`, `gemini_cli`)
- `model` — model used (e.g. `claude-sonnet-4-6`, `gpt-4o`, `gemini-flash`)
- `context` — skill output serialized as JSON, e.g. `{"summary": "...", "findings": [{"category": "Security|Bugs|...", "location": "file:line", "description": "...", "severity": "critical|high|medium|low", "confidence": "confirmed|likely", "fix_direction": "..."}]}`
- `status` — lifecycle state: `open` (default), `pending`, `done`, `fixed`, `wontfix`, `superseded`
- `parent_uuid` — UUID of a related entry (optional); enables linking entries into chains
- `relation` — how this entry relates to `parent_uuid`: `followup`, `fix`, `review`, `supersedes`
- `created_at` / `updated_at` — UTC timestamps

## Locate Project Root
Always resolve before any operation:
```bash
git rev-parse --show-toplevel 2>/dev/null || pwd
```
The DB lives at `{project_root}/.sidecar/sidecar.db`. Derive `project` as `basename` of the project root path.

## Agent & Model Identity

When calling `save`, the caller must supply `agent` and `model`.

**agent** — stable lowercase snake_case identifier for the calling runtime:

| Runtime | Value |
|---------|-------|
| Claude Code | `claude_code` |
| Gemini CLI | `gemini_cli` |
| Codex / OpenAI CLI | `codex` |
| Custom | descriptive snake_case name |

**model** — active model name from the runtime:
- Claude: from system prompt metadata or `claude --version` (e.g. `claude-sonnet-4-6`)
- OpenAI: the `model` param used in the request (e.g. `gpt-4o`)
- Gemini: the model field from the request (e.g. `gemini-2.5-pro`)
- Unknown: use `{agent}/unknown` as a placeholder

## Operations

### save
Auto-init if DB is absent, then invoke the write script:

```bash
python3 ~/.agents/skills/sidecar/scripts/add_sidecar_entry.py \
  --db-path "{project_root}/.sidecar/sidecar.db" \
  --project "{project}" \
  --skill "{skill}" \
  --scope "{scope}" \
  --agent "{agent}" \
  --model "{model}" \
  --context '{context_json}' \
  [--status open|pending|done|fixed|wontfix|superseded] \
  [--parent-uuid "{uuid}"] \
  [--relation followup|fix|review|supersedes]
```

`context_json` must be a valid JSON string. On success, prints the new entry UUID.

### read
Query entries via the read script. All filters are optional; results are returned as JSON ordered by `created_at DESC`.

```bash
python3 ~/.agents/skills/sidecar/scripts/get_sidecar_entry.py \
  --db-path "{project_root}/.sidecar/sidecar.db" \
  [--project "{project}"] [--skill "{skill}"] [--scope "{scope}"] \
  [--status open|pending|done|fixed|wontfix|superseded] \
  [--uuid "{uuid}"] [--limit N]
```

| Flag | When to use |
|------|-------------|
| `--project` | all project-scoped queries |
| `--skill` | filter by skill (e.g. `review`) |
| `--scope` | filter by scope path |
| `--status` | filter by lifecycle state (e.g. `open`) |
| `--uuid` | fetch one exact entry (skips other filters) |
| `--limit` | max results returned (default: 1) |

### update
Update the status of an existing entry by UUID:

```bash
python3 ~/.agents/skills/sidecar/scripts/update_sidecar_entry.py \
  --db-path "{project_root}/.sidecar/sidecar.db" \
  --uuid "{uuid}" \
  --status open|pending|done|fixed|wontfix|superseded
```

On success, prints the UUID. Exits with an error if no entry matches.

## Rules
- `add_sidecar_entry` auto-initializes the DB via `ensure_db` — no manual init step needed.
- `project` must match the project the DB belongs to; reject or warn on mismatch.
- `context` must be valid JSON.
- `uuid` is generated by the caller.
- Never delete entries unless explicitly instructed by the user.
- Use `datetime('now')` for all timestamps (UTC).
